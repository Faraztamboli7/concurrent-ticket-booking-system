# Concurrent Ticket Booking System

A real-time ticket booking platform with seat locking and booking management.

## Tech Stack
- React.js
- Node.js
- Express.js
- PostgreSQL
- Tailwind CSS

## Features
- Event Listing
- Seat Selection
- Seat Locking
- Seat Booking
- Auto Seat Unlock After Timeout
- Real-Time Booking Workflow
